> **Turning raw sales data into meaningful business insights.**

A Microsoft Excel-based business analysis project designed to transform raw sales records into meaningful insights through customer analysis, regional and product performance summaries, descriptive statistics, regression analysis, what-if analysis, and an interactive dashboard.

---

## 🎯 Project Overview

This workbook analyzes sales transactions across multiple customers, regions, and product categories. It brings together detailed transaction data and supporting analytical worksheets to help understand sales performance, profitability, customer contribution, and monthly trends.

The project demonstrates how spreadsheet-based analysis can support business reporting and data-driven decision-making.

## 🗂️ Dataset at a Glance

The `data` worksheet contains **200 transaction records** and 11 columns.

| Field | Description |
|---|---|
| Customer_ID | Unique customer identifier |
| Customer_Name | Customer name |
| Region | Sales region |
| Product_Category | Category of the product sold |
| Sales | Sales amount for the transaction |
| Quantity | Number of units |
| Discount | Discount applied |
| Order_Date | Date of the order |
| Profit | Profit generated from the transaction |
| date/time | Date and time field included in the source worksheet |
| Customer_ID2 | Additional customer/date-related field included in the source worksheet |

**Order-date coverage:** 10 April 2024 to 7 April 2025.

## 📁 Workbook Structure

The workbook contains the following principal worksheets:

| Worksheet | Purpose |
|---|---|
| `data` | Source transaction records |
| `CustomerSummary` | Customer-wise sales, profit, order count, ranking, and Top 10 indicator |
| `WhatIf` | What-if analysis of the impact of discount changes on total profit |
| `MonthlySales` | Monthly sales, monthly profit, and growth compared with the prior month |
| `DescriptiveStats` | Descriptive statistical measures for sales, quantity, discount, and profit |
| `Regression` | Regression analysis examining the relationship between sales and profit |
| `PivotTable` | Pivot-style summary of sales by region and product |
| `Dashboard_tabal` | Supporting summary tables for dashboard reporting |
| `Dashboard` | Dashboard presentation worksheet |

## 🔍 Key Analysis Areas

### 👥 1. Customer Analysis
- Reviews customer-level purchase value and profit.
- Summarizes order counts.
- Includes customer ranking and a Top 10 indicator.

### 💰 2. Sales & Profitability Analysis
- Examines sales and profit across product categories.
- Compares performance across regions.
- Uses summary tables to organize business performance information.

### 📅 3. Monthly Performance
- Summarizes monthly sales and profit.
- Includes growth compared with the previous month.

### 📈 4. Descriptive Statistics
- Provides statistical summaries for sales, quantity, discount, and profit.
- Helps understand central tendency and variation in the transaction data.

### 📉 5. Regression Analysis
- Includes a regression model titled **Profit vs Sales**.
- Provides regression statistics to examine the relationship between sales and profit.

### 🧮 6. What-If Analysis
- Examines the potential impact of discount changes on total profit.
- Supports scenario-based evaluation.

### 📊 7. Dashboard Reporting
- Brings selected analysis outputs together in a dashboard worksheet for easier review.

## 🚀 How to Use

1. Open the workbook in Microsoft Excel or a compatible spreadsheet application.
2. Start with the `data` worksheet to review the transaction-level records.
3. Explore `CustomerSummary`, `MonthlySales`, and `PivotTable` for summarized results.
4. Review `DescriptiveStats`, `Regression`, and `WhatIf` for analytical outputs.
5. Open the `Dashboard` worksheet for the consolidated visual overview.

For the best experience, use a spreadsheet application that supports the workbook's formulas, pivot tables, and dashboard elements.

## 💡 Project Purpose

The purpose of this project is to apply practical data-analysis concepts to sales information and present the results in a structured, understandable format. It connects spreadsheet skills with business questions such as:

- Which customers contribute to sales and profit?
- How do regions and product categories perform?
- How do sales and profit change month by month?
- What statistical patterns appear in the data?
- How may discount changes affect profitability?
